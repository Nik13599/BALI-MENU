# BALI ID: первоначальное ознакомление и выпуск карты

Выпуск BALI ID больше не производится автоматически после регистрации профиля. Перед первым входом в раздел гость читает описание функций, прокручивает его до конца и нажимает **«Ознакомлен»**. Подтверждение версии 1 сохраняется один раз в `users/{uid}/baliIdAgreements/privilege` с серверной отметкой времени.

Только после успешной записи подтверждения модуль карты может создать `baliIds/{uid}` вместе с последовательным счётчиком и исходным статусом Member. Firestore Rules также запрещают выпуск номера, изменение счётчика и создание привилегии Member без действующего подтверждения. При отмене/ошибке сохранения карту не создаём. Прямой URL `#id`, история браузера, меню профиля и домашняя карточка проходят ту же проверку. Подтверждение повторно не запрашивается при последующих посещениях того же аккаунта.

## Порядок публикации

1. **Сначала** опубликовать обновлённые правила Firestore для Firebase-проекта BALI. Это отдельная операция с учётными данными владельца: `firebase deploy --only firestore:rules --project bali-menu-5a48b`.
2. **Затем** публиковать HTML/JS/CSS с этим интерфейсом (или объединять PR, если сайт развёртывается из `main`). До публикации правил новое подтверждение не сможет записаться; свежие карты выдаваться не будут.
3. Запустить `npm test`. Проверить в тестовом аккаунте отсутствие новой записи `baliIds/{uid}` до подтверждения; блокировку кнопки до прокрутки; создание BALI ID после подтверждения; отсутствие повторного окна после обновления; закрытие окна без присвоения карты; отказ при прямом `#id` до подтверждения.
4. Проверить пользователя с ранее выданной картой, но без записи ознакомления: окно появляется один раз, прежний номер сохраняется после подтверждения.

**Важно:** клиентский интерфейс может фиксировать достижение конца текста и явное нажатие кнопки, но технически невозможно подтвердить, что пользователь прочёл и понял каждое предложение. Запись фиксирует заявленное ознакомление, а не прочтение глазами.

Данный PR не развёртывает Firebase Rules автоматически.
