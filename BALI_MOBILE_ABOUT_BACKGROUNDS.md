# Мобильный блок «О клубе»: сменяемые фоны

## Где редактировать

Админка `admin.html` → **Дизайн главной** → нажмите **Телефон** в живом предпросмотре → нажмите на верхнюю карточку **«О клубе»**. Справа появится редактор **«Мобильный блок „О клубе“»**.

Можно одновременно выбрать и загрузить до **8 изображений** JPG / PNG / WebP / HEIC (каждое до 15 МБ). Файлы автоматически сжимаются до небольших WebP для Firebase. Для лучшей композиции рекомендуем горизонтальные фоны 1200×600 px, главный объект справа, чтобы слева оставались видимыми надписи и кнопка «О КЛУБЕ».

Каждую фотографию можно отдельно:
- поднять или опустить в порядке показа;
- скрыть или опубликовать;
- окончательно удалить.

Если опубликован один фон — он статичен. Если несколько — на телефоне изображения сменяются каждые **8,5 сек.** с плавным затуханием. Есть ручные индикаторы для переключения. При системном режиме уменьшения анимации автосмена отключена. При отсутствии фотографий показывается тёмный фирменный градиент без пустого изображения.

## Техническое устройство

- HTML/CSS: `index.html`, `bali-mobile-about-hero.css`.
- Клиент: `bali-mobile-about-hero.js`, доступ **только на чтение опубликованных**.
- Редактор: `bali-mobile-about-admin.js` и `bali-mobile-about-admin.css`.
- Модуль сжатия: `image-compressor.js`, профиль `design-mobile-about-hero` (WebP ~120 КБ; 2:1).
- Firestore: **отдельная коллекция** `mobileAboutBackgrounds/{docId}`: `imageUrl`, `sort`, `published`, `updatedAt`. Это **не** `settings/homeDesign`, поэтому редактирование ПК-карточки не удаляет мобильные фоны.
- Firestore Rules: все изменения только для подтверждённых `admins/{uid}`, гости могут запрашивать только `published == true`.

## ВАЖНО: публикация Firestore Rules

GitHub Pages публикует HTML/JS/CSS, **но не Firestore Rules**. Для использования нового редактора владелец Firebase должен отдельно опубликовать `firestore.rules` из основной ветки.

Пример для владельца с корректно настроенной Firebase CLI:

```bash
firebase deploy --only firestore:rules --project bali-menu-5a48b
```

До публикации правил **сайт и оформление будут опубликованы**, но попытка загрузить фон или читать коллекцию может отвечать `permission-denied`. Клиент автоматически оставляет тёмный фон. Не открывайте все записи/чтения правил ради работы галереи.

В существующем редакторе ПК блок `О клубе` и его отдельные изображения для планшета/телефона остались без изменений.
