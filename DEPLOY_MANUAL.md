# Публикация BALI MENU: текущий статус

Это **не руководство к немедленному публичному запуску**. Приём заказов пока выключен.

1. Завершите [AUTH_SETUP.md](AUTH_SETUP.md): Firebase Google Sign-In, Firestore, правила `firestore.rules`, реальные настройки `firebase-config.js`.
2. Реализуйте и протестируйте отдельный серверный API: проверка Firebase ID Token, цен, права владельца, ролей администратора, редактирование заказа и запись в Google Таблицу.
3. Проверьте регистрацию, защиту профилей и обработку ошибок в браузере на телефоне и компьютере.
4. Только после этого можно включать Firebase Hosting или GitHub Pages (HTTPS).

До выполнения этих условий GitHub Pages может использоваться для просмотра внешнего вида, но не для реального приёма личных данных и заказов.
