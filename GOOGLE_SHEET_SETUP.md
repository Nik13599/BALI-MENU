# Google Таблицы BALI

[Открыть таблицу проекта](https://docs.google.com/spreadsheets/d/1g29MM-3RO2gg8ihwFWrHjf24XqZO3N1B1BdUVT2rbkw/edit)

В таблице уже предусмотрены заказы, меню, мероприятия, баннеры, администраторы и журнал изменений.

**Не выполняйте старую функцию `setupDatabase()` из исходного шаблона.** Она была опасной: могла очищать существующие вкладки и добавлять тестовые данные; в репозитории BALI она отключена.

Интеграцию с Google Таблицами нужно реализовать через отдельный защищённый серверный API, который проверяет Firebase ID Token, владельца заказа, подлинные цены и права администратора, а потом записывает заказ на вкладку по дате мероприятия.

Email, имя и телефон гостей должны храниться с ограниченным доступом. Не открывайте основную таблицу для публичного редактирования.
