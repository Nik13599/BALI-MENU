## Чайная карта по дополнительным пожеланиям

Категории переведены из верхнего регистра в обычный; названия сохранены дословно. Цена выделена отдельно, без повторяющегося яркого `BYN 18.00`. Валюта менее заметная, длинные названия переносятся целыми словами. Удалён значок ⓘ в правом верхнем углу. Для позиций с описанием есть спокойное действие «Подробнее о чае →» и нажатие по всей карточке; окно сохраняет описание, вкус, состав и заваривание из существующих данных. У позиций без описания нет неработающей кнопки. На ПК остаются шесть колонок, на телефоне — вертикальный список.

Публикация, слияние PR и рабочие записи Firebase не выполнялись. Детальные действия для рабочего запуска — [OPERATIONS.md](OPERATIONS.md).

## Единое оформление меню

Кухня, бар, кальянная и чайная карты используют общий стиль карточек, заголовков и цен: Manrope, тёмная поверхность, спокойная валюта BYN. Для ознакомительных карт разметка карточек и групп вынесена в `bali-menu-cards.js`; общий CSS — `bali-menu-cards.css` в гостевом бандле. Старые переопределения чайных карточек заменены общим оформлением, отдельный файл оставляет только оформление чайного диалога.

На ПК сохранены шесть колонок, на телефоне — вертикальный список и четыре кнопки по 46 × 46 px. На планшете — три колонки. В каждой порции бара/кальянов объём стоит рядом с соответствующей ценой. Категории и их счётчики одинаковы во всех картах. Источники данных и значения цен сохранены, демонстрационные позиции используются только изолированными тестами.

Заказ, количество и добавление в корзину доступны в кухне. У кухонных блюд с подробным описанием вместо углового значка появилась кнопка «Подробнее о блюде»; диалог использует существующую корзину и количество. В остальных картах действий заказа нет. Поиск остаётся скрыт, возрастное подтверждение бара и кальянов сохранено.

Проверки: исходные ограничения и backend-тесты (`npm test`), актуальность CSS-бандла (`npm run check:styles`), браузерные сценарии на ширинах 320, 390 и 1440 px. Новые сценарии проверяют одинаковые стили, варианты объёмов/цен, фильтры, отсутствие действий заказа в ознакомительных картах, количество в диалоге кухни, сохранение корзины при переключении карт, фотографии/ошибки загрузки и доступность. Внешние запросы этих тестов изолированы; записи в рабочую Firebase не выполняются.
