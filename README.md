# BALI MENU — онлайн-меню и предзаказы к столику

Проект ночного клуба **BALI (Минск)**. Основа HTML/CSS интерфейса перенесена из [skillsatsugeco/food-ordering-tracking-app](https://github.com/skillsatsugeco/food-ordering-tracking-app) и дорабатывается под предзаказы BALI.

## Регистрация гостя (код готов, активация Firebase — отдельно)

- Вход через **Google или Apple**, с обязательным подтверждённым email. Apple может выдать защищённый адрес-посредник вместо настоящего email; для веб-входа требуется настройка Apple Developer.
- При первой регистрации гость **обязательно** указывает **имя** и **номер телефона** в международном формате.
- Email подтягивается из Google и защищён от изменения в форме.
- Профиль `users/{uid}` сохраняется в Firestore. Просмотр и редактирование доступны только владельцу; права ограничены `firestore.rules`.
- При повторном входе профиль загружается автоматически, имя и телефон можно изменить.
- Пока профиль не заполнен, корзина не переходит к оформлению предзаказа.
- Телефон сейчас **не подтверждается через SMS**.

**[Как включить регистрацию: AUTH_SETUP.md](AUTH_SETUP.md)**  
**[Как подключить вход через Apple: APPLE_SIGNIN_SETUP.md](APPLE_SIGNIN_SETUP.md)**

## Статус проекта

**Firebase Web App зарегистрирован в проекте `bali-menu-5a48b`; публичная веб-конфигурация добавлена в `firebase-config.js`.** Сайт пока НЕ опубликован, Google Sign-In и Firestore ещё необходимо включить и настроить, реальные заказы НЕ принимаются.

Перед входом гостей требуется включить провайдер Google в Firebase Authentication, создать Firestore и применить `firestore.rules`. Публикацию разрешать только после проверки правил доступа и настройки защищённого серверного API для заказов.

Текущий унаследованный `Code.gs` — лишь источник для будущей переработки. Опасные функции примера (пароль администратора, создание заказов без проверки Google ID Token, удаление данных при настройке, публичное чтение заказов) отключены. Не публикуйте его как рабочий сервер без отдельной проверки.

## Структура

- `index.html`, `styles.css`, `app.js`: меню, корзина и форма предзаказа
- `auth.css`, `auth.js`, `firebase-config.js`: вход через Google и обязательный профиль
- `firestore.rules`, `firebase.json`: правила хранения пользовательских данных
- `admin.html`, `admin.js`, `admin.css`: заготовка панели администратора (нужна серверная авторизация)
- `track.html`, `track.js`: заготовка просмотра статуса заказа
- `Code.gs`: старый Google Apps Script шаблона, небезопасные операции отключены
- `AUTH_SETUP.md`: инструкции для владельца проекта

## Функциональные требования BALI

- Дата мероприятия, номер столика, еда и напитки, цены в BYN.
- Редактирование предзаказа до подтверждения администратором.
- Управление меню, баннерами, заказами и печатью в админ-панели.
- В Google Таблице отдельная вкладка на каждую дату мероприятия, журнал изменений.

**Рабочая таблица:** https://docs.google.com/spreadsheets/d/1g29MM-3RO2gg8ihwFWrHjf24XqZO3N1B1BdUVT2rbkw/edit
