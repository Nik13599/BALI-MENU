# BALI MENU — предзаказы ночного клуба BALI

Основано на интерфейсе [food-ordering-tracking-app](https://github.com/skillsatsugeco/food-ordering-tracking-app) (лицензию оригинала и условия использования необходимо проверить).

**Статус: импортирована основа, не готово для реальных заказов.** В оригинале использовались небезопасная парольная авторизация администратора и отсутствие проверки личности гостя. В этой версии серверные админ-операции и создание заказов заблокированы до реализации безопасной авторизации. Чужой Apps Script URL и контакты удалены.

## Файлы
- index.html, app.js, styles.css — каталог и корзина
- admin.html, admin.js, admin.css — интерфейс администратора (серверные операции пока отключены)
- track.html, track.js — отслеживание
- delivery.html, delivery.js — исходный раздел доставки; в BALI будет заменён обслуживанием столиков
- Code.gs — пример интеграции с Google Таблицами (не публиковать до переработки авторизации)

## Требования BALI
1. Предзаказ на выбранную дату мероприятия и столик, валюта BYN.
2. Вход через Google, контактный телефон, личные заказы и изменения до подтверждения.
3. Администратор: меню, цены, рекламные баннеры, заказ и печать.
4. Отдельная вкладка Google Sheets для каждой даты мероприятия и история изменений.
5. Серверная проверка стоимости, доступа и статусов, закрытие заказов в нужное время.

Google Таблица: https://docs.google.com/spreadsheets/d/1g29MM-3RO2gg8ihwFWrHjf24XqZO3N1B1BdUVT2rbkw/edit

## Важное
Настройка API_URL в app.js, admin.js, track.js и delivery.js пока содержит заглушку. GitHub Pages можно включать только для демонстрации интерфейса, не для обработки персональных данных или действительных заказов.
