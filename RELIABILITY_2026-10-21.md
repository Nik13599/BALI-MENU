# Проверка ошибок и скорости · 21 октября 2026

Исходная версия: `b906cc2`. Исправления сохраняют существующие разделы, оформление, цены и правила работы с заказами.

## Исправления

- При смене аккаунта старый ответ загрузки профиля больше не может подменить профиль нового пользователя. Сохранение захватывает пользователя и номер сессии до первого запроса; после смены сессии оно не начинает запись и не обновляет интерфейс другого аккаунта.
- Ошибка выхода из аккаунта отображается в форме вместо необработанного отклонения Promise.
- Загрузка заказов гостя сразу очищает предыдущую сессию и показывает состояние загрузки. Промежуточное состояние не считается первым снимком для уведомлений.
- Списки заказов гостя, администратора и выбранной даты отклоняют запоздавшие результаты предыдущего снимка. Ошибки и смена сессии также отменяют публикацию незавершённых результатов.
- Общий `bali-order-snapshots.js` заменяет три копии загрузки состава заказов и расчёта суммы. Неизменившиеся документы используют уже загруженные строки, параллельные снимки разделяют незавершённый запрос. Ошибки не кешируются навсегда; удалённые заказы и данные прежней сессии освобождаются.
- Календарь строит индекс событий один раз за отрисовку и повторно использует форматтер часов. Раньше индекс строился заново для каждого дня месяца и недели.
- Все подключённые стили перенесены в упорядоченный манифест сборки. Проверка сборки запрещает случайное возвращение отдельных CSS-подключений.

## Воспроизводимая проверка

```sh
npm ci
npm test
npm run check:styles
npx playwright install chromium
npm run test:browser
npm run test:firebase
```

Новые проверки покрывают смену аккаунта во время загрузки и сохранения профиля, ошибку выхода, обратный порядок ответов заказов, выход при незавершённом запросе, число подключений CSS и отсутствие полного обхода событий для каждой ячейки календаря. Отдельные тесты проверяют число чтений для 100 заказов, совместное ожидание запроса, повтор после ошибки и очистку кеша.

Существующий набор проверяет корзину, каталог и редакторы, календарь и афиши, BALI ID и QR, адаптивную геометрию, доступность и backend. Firebase Emulator выполняет настоящий клиент заказов и проверяет правила доступа в изолированном `demo-bali-menu`.

Кеш состава ограничен одной подпиской. Корректность обновления опирается на существующий контракт: изменение строк заказа атомарно обновляет родительский документ заказа. Этот контракт соблюдают клиент гостя и редактор администратора. При добавлении новых способов редактирования его нужно сохранить.

Рабочие данные и правила Firebase этими изменениями не мигрируются. Реальный Google OAuth и доступность внешних сервисов не заменяются изолированными тестами. Публикация интерфейса выполняется существующим GitHub Pages из `main`.
