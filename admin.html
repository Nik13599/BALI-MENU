    CSV / Excel

    Выберите дату и конкретное мероприятие. Выгрузка получает все доступные за 30 дней предзаказы выбранного мероприятия из базы, а не только последние 100 заявок.

    Доступ сотрудников к предзаказам · логин и пароль

    Назначайте сотрудникам отдельные учётные записи. Доступ открывает только страницу предзаказов, без прав на остальную админку. Пароли не сохраняются в базе данных и не отправляются по почте.

    Настройка Firebase для регистрации сотрудников

    Серверная функция сотрудников ещё не готова. Для её запуска требуется однократная настройка владельцем Firebase проекта bali-menu-5a48b.

    1. Убедитесь, что проект Firebase использует тариф Blaze и для него настроены уведомления о расходах.
    2. В Google Cloud включите API Cloud Functions, Cloud Build и Artifact Registry.
    3. В разделе IAM проверьте необходимые права для bali-firestore-deploy@bali-menu-5a48b.iam.gserviceaccount.com на развёртывание Cloud Functions. Не выдавайте доступ всем пользователям.
    4. В Firebase Authentication включите способ входа «Email/Password», не отключая Google.
    5. Повторно запустите публикацию функций сотрудников, затем нажмите «Обновить» в этом разделе.

    До трёх отдельных афиш на одну дату. Отметки «Хочу пойти» сохраняются у гостей только в браузере.

    Настройки мероприятия

    Минск

    Время события отображается под афишей, например 20:00–23:00. Время закрытия предзаказов настраивается отдельно.

    Все афиши сохраняются квадратными — 1:1 (рекомендуется 1000 × 1000 px). Название, дата, время и описание отображаются только при открытии афиши. На главной — маленькое сердечко, в календаре — кнопки действий.

    Для каждого мероприятия предзаказ включается отдельно. Гость выбирает дату, название мероприятия и позиции кухни.

    Скопировать актуальные правила с GitHub → открыть Firebase Rules и нажать Publish. Не удаляйте коллекции и документы Firestore.

    Правила публикации в стиле BALI · откройте перед сохранением

    Каждый экран должен отвечать на три вопроса: что здесь происходит, чем это интересно гостю и куда нажать дальше.

    • Афиша: проверенная дата, время, название и читаемая картинка. Не обещайте то, чего нет в программе.
    • Аренда: конкретный формат события и достоверные преимущества площадки. Одна главная кнопка действия.
    • Изображения: проверьте кадрирование отдельно на телефоне, планшете и компьютере. Не размещайте мелкий текст внутри фото.
    • Цены, состав блюд и привилегии: обновляйте только по подтверждённым данным, после сохранения проверяйте гостевую версию.
    • Контроль: проверьте контраст, размер на телефоне, работу кнопок, доступность с клавиатуры и отсутствие лишней анимации.
